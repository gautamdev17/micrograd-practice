# micrograd-practice

> **Building backprop from scratch, one gradient at a time.**  
> A personal re-implementation of [micrograd](https://github.com/karpathy/micrograd) to understand automatic differentiation and neural networks from the ground up.

## 📚 About

This project is my hands-on journey into the core mechanics of deep learning.  
No frameworks. Just Python, math, and curiosity.

Goals:
- Recreate the core engine step by step.  
- Build intuition around computational graphs and backpropagation.  
- Extend the base implementation with personal experiments.

## 🧠 Features (Planned & In Progress)

- Scalar engine with autograd ✅  
- Backpropagation from scratch ✅  
- Basic neural net training loop 🛠️  
- Extra modules and experiments 🧪  
- Visualization and notebooks (coming soon)

## 📝 Notes

This is a learning project. Things might break, mutate, or get rewritten as I go.  
Perfect isn’t the goal — understanding is.
